# Rule: Control Plane Source of Truth

1. `.ai/` is the only canonical source of truth.
2. Tool-specific files are generated adapters. The `tools` table in `.ai/config.yaml` is the only authoritative roster and adapter registry; missing, unreadable, or schema-invalid config fails closed.
3. Generated adapters must not be edited manually unless explicitly marked.
4. Generated adapter edits are not synced back into `.ai/` automatically.
5. Legacy `.agents/` content is reference material unless generated by `__AI_COMMAND_SYNC__`.
6. The repository is the handoff medium between separate applications.
7. Manual app switching is expected and must be documented in dispatch prompts.
8. Antigravity's always-loaded prompt is generated at repository root as `GEMINI.md`.
9. `.agents/rules/` and `.agents/skills/` are conditional Antigravity support material.
10. Do not rely on `.agents/workflows/`, `.agents/context/`, or `.agents/agents/` for default Antigravity behavior; workflows must be embedded in `GEMINI.md`.
11. Canonical workflows, skills, and rules use neutral command-token placeholders for adapter-facing commands. The shared renderer must resolve every token from the selected tool's config entry and reject unknown or surviving tokens.
